## 检查分工

| 范围 | 确认的问题或检查目标 | 验证方式 |
| --- | --- | --- |
| 启动连接 | 精确账户路由超时；自动连接与显式连接可能重叠，不能据此认定外部根因 | 源码追踪、有界恢复正反例、公开状态摘要 |
| 停止 | 原等待范围可能覆盖命令自然结束时间；公开状态先更新、停止 IPC 后完成，下一操作可能被内部忙碌状态拒绝 | 提前结束期限反例、真实子进程、等待实际停止调用完成 |
| MCP 拒绝 | 原筛选器可能忽略其他参数或其他工具调用 | 必须唯一工具项、额外调用反例、实际协议/UI 拒绝链 |
| 刷新 | 页面标题出现不代表审批卡片已经投影到 React | 延迟初始 snapshot 的 GUI 反例、可见条件等待 |
| 诊断 | 取消、实际脱敏输出、允许字段和合成标记均须验证 | 真实主进程 IPC 与文件导出，不读取认证 |
| 重启和清理 | 区分启动器、Electron 主进程、引擎子进程；确认任务恢复且不重放 | 实际 native PID/创建时间观察与独立 fixture |

## 验证边界

离线 GUI 测试使用真实桌面代码、渲染器和协议适配器，但使用明确标注的测试协议服务和全新独立数据目录。它不使用官方认证、不调用模型，也不代替实际 SID1006 或真实服务可用性验收。

测试中的故障注入和模拟账户仅用于证明客户端流程；不能证明模型必然遵从提示、真实账号路由已恢复或真实 MCP 服务当前可用。真实账户重跑必须在本轮离线验证及统一回归完成后另行安排。
